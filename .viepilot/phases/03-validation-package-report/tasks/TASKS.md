# Phase 3 Task Cards

## 3.1 Regression/evidence

Rerun frozen RC test matrix and save traceable logs/screens/metrics. Fix regression/P0 only.

## 3.2 Language quality analysis

Analyze Chinese and English separately: ASR, translation, protected tokens, pronunciation, timing and human edits.

## 3.3 Guide/demo

Document clean setup, profiles, review workflow, recovery and troubleshooting in Vietnamese; record a short honest demo.

## 3.4 Export/report UI

Persist output, encoder/fallback, provenance/resource manifest and benchmark summary in the project/export record.

## 3.5 License audit

Audit every shipped code/model/binary/voice asset; exclude unclear assets and record voice consent.

## 3.6 Product report

Write evidence-backed objectives, architecture, method, per-language results, limitations, risks and future work.

## 3.7 Acceptance/release

Run final acceptance, package, smoke, hash and version. Tag only when the gate passes.
