# Phase 3 Spec — Validation, Package & Report

## Objective

Protect RC1 from scope growth, validate it on the target machine, package it with licenses/checksums and deliver Vietnamese usage/troubleshooting plus a measured product report by Day 21.

## Deliverables

- Full regression and final golden evidence.
- Separate zh→vi and en→vi quality/resource analyses.
- Vietnamese setup/use/troubleshooting guide and short demo.
- Export/report UI persistence and final manifest.
- Third-party license/provenance audit.
- Release zip/checksum/version manifest and final report.

## Scope control

Only regression and P0 fixes. A failed gate delays/tag-withholds the release; it does not authorize feature removal from evidence or unsupported claims.

## Exit criteria

All Day 21 commands pass or documented limitations explicitly block the tag. Deliverables are reproducible from the repository and resource manifest.
