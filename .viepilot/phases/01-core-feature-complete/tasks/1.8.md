## File-Level Plan

- Header — expose Studio/Bản dịch/Lồng tiếng/Tài nguyên navigation and Vietnamese preview/generate/export actions.
- Stage rail — map persisted steps/artifacts to five explicit text states and an overall percentage.
- Operations — keep progress and logs reopenable; expose stop while running and resume from persisted state after stop/failure.
- Reliability — retain QThread ownership rules and remove forced thread termination from the normal stop path.
- Tests/docs — cover deterministic workspace state mapping, navigation and operation control semantics offscreen.

## Best Practices

- All QWidget access stays on the GUI thread; worker completion/progress crosses queued signals.
- Pipeline state is explicit: queued/running/review/done/error/cancelled.
- Stop is cooperative and bounded; never use `QThread.terminate()` as the ordinary path.
- Resume reads persisted state and does not discard completed stage artifacts.
- Preserve unrelated user changes.

## Acceptance Criteria
