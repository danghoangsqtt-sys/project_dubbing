## File-Level Plan

- Launcher view model — expose deterministic device, profile, resource and recent-project presentation state.
- Launcher UI — implement the approved dense/calm hierarchy, Vietnamese labels, status pills, responsive three-column cards and keyboard-accessible actions.
- Project entry — accept supported local video through file picker, recent card or drag/drop while preserving resource gating and safe project resume.
- Tests/evidence/docs — exercise pure state mapping and offscreen Qt interactions; save a production launcher screenshot.

## Best Practices

- Keep widgets on the Qt main thread; do not run model/media work from event handlers.
- Pair every status color with text; give important actions accessible names/tooltips.
- Read persisted state without mutating it and preserve canonical cue data.
- Use local paths and argument-list subprocess calls only.
- Preserve unrelated user changes.
