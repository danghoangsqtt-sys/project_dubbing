## File-Level Plan

- `app/media_contract.py` — run bounded argument-list ffprobe/FFmpeg capability probes; validate required streams/duration and produce a serializable export plan.
- Subtitle builder/adapter — validate cue output and atomically write UTF-8 SRT, surfacing failures instead of silently returning success.
- `app/workflows/export_workflow.py` — preflight input/SRT/audio, keep the “both” intermediate mux as video stream-copy, validate final MP4 before marking done, and save encoder/fallback/single-pass report facts.
- Tests/docs/state — cover Unicode SRT under forced TTS failure, probe parsing, NVENC selection, fallback policy, failure behavior and one-encode orchestration without external dependencies.

## Best Practices

- Use argument arrays, `shell=False`, bounded timeout, checked return codes and UTF-8 diagnostics.
- Probe both source and completed output; output success requires video stream and positive duration.
- Detect bundled FFmpeg NVENC support before selecting it; retain deterministic libx264 fallback.
- Intermediate audio replacement must stream-copy video so only the final render encodes video once.
- SRT generation must not depend on TTS/audio artifacts.
- Preserve unrelated user changes.

## Acceptance Criteria

- [ ] UTF-8 Vietnamese/Chinese SRT writes atomically and remains available when TTS fails.
- [ ] ffprobe validates source/final streams and duration with actionable failures.
- [ ] bundled FFmpeg capability selects NVENC when present and records libx264 fallback.
- [ ] subtitle, voice and both export paths perform at most one full video encode.
- [ ] final output is probed before project state is marked done and report facts are persisted.
- [ ] Tests, compilation and regression preflight pass; commits/tags are remotely persisted without unrelated files.
