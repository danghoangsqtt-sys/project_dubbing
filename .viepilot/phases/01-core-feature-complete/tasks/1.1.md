## File-Level Plan

- `.python-version` — declare Python 3.11 as the source-run contract.
- `tools/__init__.py` and `tests/__init__.py` — make the diagnostic and its standard-library tests importable without adding runtime dependencies.
- `tools/bootstrap_python311.ps1` — locate `py -3.11`, safely create/reuse `.venv`, validate interpreter version, upgrade packaging tools, and install the selected requirements profile.
- `tools/preflight.py` — collect sanitized OS/CPU/RAM/Python/package/GPU/FFmpeg/NVENC/resource/video facts, optionally run an offscreen GUI smoke, emit readable console output and atomically write JSON.
- `tests/test_preflight.py` — test parsers, status aggregation, resource inventory and report writing without network/GPU/model downloads.
- `docs/development-setup.md` — document clean setup, commands, generated evidence, current limitations and recovery.
- `README.md` — point source users to the reproducible setup/preflight guide.
- `artifacts/evidence/day-1-preflight.json` — record the actual target-machine result using repo-relative/redacted paths.
- ViePilot state files — record start/result, exact evidence and next task; do not modify user-owned dirty implementation files.

## Best Practices

- Use only Python standard library in preflight so it can diagnose an incomplete environment.
- Resolve bundled FFmpeg/ffprobe from the repository before `PATH`.
- Pass subprocess arguments as arrays with `shell=False`, timeout and captured stderr.
- Never read `.env`, emit secrets, download models or execute network providers.
- Treat missing optional/full-pipeline resources as `warning`; Python 3.11, virtualenv, base GUI packages, FFmpeg/ffprobe, H.264 encoder and valid video probe are required.
- Generate evidence atomically as UTF-8 JSON and keep machine paths repo-relative where possible.
- GUI smoke uses Qt offscreen mode, bounded timeout and a generated local clip; it must not enter an interactive launcher loop.
- Preserve the four pre-existing dirty files (`CapCap.spec`, `requirements-local.txt`, `ui/worker_adapters/__init__.py`, `ui/worker_adapters/processing_workers.py`).
