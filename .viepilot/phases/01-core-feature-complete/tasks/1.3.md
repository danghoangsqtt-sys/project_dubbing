# Task 1.3 — Lock Faster-Whisper zh/en Transcript Path

## Status

`in_progress` — started 2026-09-10.

## Objective

Make Faster-Whisper transcription deterministic for the supported Chinese (`zh`) and English (`en`) modes. The workflow must reject ambiguous languages, materialize inference inside the worker boundary, create editable canonical timed cues, and persist the full ASR configuration and model revision in project and cue provenance.

## File-Level Plan

- `app/asr_config.py` — define and validate the supported language and Faster-Whisper inference contract; resolve model identity/revision and package/runtime provenance without loading a model.
- `app/whisper_processor.py` — consume the canonical ASR config, keep the segment generator materialized under the transcription lock, and return confidence/language metadata suitable for canonical cues.
- `app/engines/whisper_adapter.py` and `app/services/engine_runtime.py` — expose the validated configuration/provenance boundary to workflows while preserving compatibility APIs.
- `app/services/project_service.py` — include the complete ASR configuration and revision in transcription cache signatures.
- `app/services/segment_service.py` — attach source language, confidence, and ASR provenance while producing stable editable cue IDs.
- `app/workflows/prepare_workflow.py` — enforce explicit `zh`/`en` for Faster-Whisper, persist requested/effective config and stage provenance, and apply it to every cue in both cached and fresh paths.
- `tests/test_asr_contract.py` — deterministic tests for language rejection, configuration, revision/signature invalidation, Unicode, timestamps, stable IDs, provenance, and eager generator consumption.
- `docs/asr-transcription.md` — document the locked modes, RTX 3060 defaults, fallback behavior, provenance, and offline model expectations.
- ViePilot state and `CHANGELOG.md` — record start/completion and evidence while excluding unrelated user changes.

## Best Practices

- Force `zh` or `en`; never silently auto-detect in the milestone path.
- Pin and persist model identity/revision, engine/package version, device, compute type, beam size, VAD, word timestamps, task, and batching choice.
- Consume Faster-Whisper’s lazy generator while the worker/GPU lock is active.
- Preserve Unicode, timestamps, word timing, confidence, stable IDs, and independent text fields.
- Keep CPU/int8 as an explicit fallback and make requested versus effective runtime visible.
- Do not download models or require CUDA/network in deterministic tests.
- Preserve the four pre-existing dirty user files.

## Acceptance Criteria

- [ ] Faster-Whisper accepts explicit `zh` and `en`, rejects `auto`/unsupported languages with an actionable error, and always uses task `transcribe`.

- [ ] Chinese and English Unicode text becomes editable canonical cues with valid timestamps, stable IDs, confidence, source language, and ASR provenance.

- [ ] Task-specific tests, full deterministic tests, compilation, and regression preflight pass.
